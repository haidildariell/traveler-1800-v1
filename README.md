# One Sentence for a Traveler from 1800

A make.fun bounty entry: a small program that writes one single sentence explaining the modern internet to a traveler who has just arrived from the year 1800, built only from things he already knows — a post office, letters, books, and a parlour.

Bounty: https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb

## How to run

    python3 main.py

The program writes the sentence (195 characters, no trailing newline) to /output/entry.txt, or to ./output/entry.txt when /output is not writable.
